## 변경

- 401이면 보호된 발행 내용·기관 키·감사 기록·이전 결과를 제거하고 재로그인 이동을 제공합니다.
- 403/404/409/422/429/503과 연결/timeout을 구분합니다. 입력 오류는 연결 재시도를 표시하지 않습니다.
- 읽기 전용 verify·login·AI 실패를 변경 작업의 결과 미확인으로 표시하지 않습니다.
- 변경 요청의 응답이 유실되면 결과 미확인을 표시하며 자동 재전송하지 않습니다.
- 운영자 activate 재시도는 기관 신청·사유가 같으면 동일 request ID를 유지합니다.
- 입력/화면 변경 뒤 늦게 도착한 조회 결과를 적용하지 않고 같은 계정의 폼을 목록 갱신 때 보존합니다.
- 발행 오류 입력으로 focus를 이동하고 대기/오류를 보조 기술에 알립니다.
- 조회 범위·검사 근거·확인 시각과 현재 사용 가능 여부의 차이를 표시합니다.
- 사용자 지시대로 `해커톤 본선/웹 디자인` 소스와 빌드에도 반영했습니다. 기존 command는 index에서 시작합니다.
