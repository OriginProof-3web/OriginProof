# 로컬 웹 작업 위치

사용자님은 2026-10-06부터 W5/W6/W7 변경을 이 `해커톤 본선/웹 디자인` 폴더에서 바로 확인하기로 지정하셨습니다.

- 사용자에게 보여주는 메인·기업·개인·관리자 화면 소스는 이 폴더에 반영합니다. TypeScript/React 변경 후 여기서 `node build.mjs`로 bundle을 갱신합니다.
- `협업 테스트 시작.command`는 이 폴더를 먼저 빌드한 다음 `http://127.0.0.1:8768/index.html`을 엽니다. 새 테스트 사이트·별도 진입점을 만들지 않습니다.
- Git PR용 `apps/web/official`에도 같은 변경을 반영합니다. 다른 worktree에서 개발하면 완료한 변경과 빌드 결과를 이 폴더에 반영하고 실행 경로를 확인합니다. 작업 중 상태를 완료로 표시하지 않습니다.
- collaboration-results.json/js 및 과거 검사 기록·이미지·사용자 설정은 소스 복사 과정에서 보존합니다.
- API·DB·체인 소스/검증 SHA는 화면 버전과 별개입니다. DB reset·운영 배포·외부 게시 없이 기존 합성 환경을 사용합니다.
