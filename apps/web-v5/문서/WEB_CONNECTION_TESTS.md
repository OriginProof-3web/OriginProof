## 실행

`협업 테스트 시작.command`를 더블클릭하면 **index.html**부터 엽니다. 실행 중인 서버는 재사용합니다. 개인 로그인에서 기존 요청하신 운영자 테스트 계정으로 관리자 화면에 들어갈 수 있습니다. 관리자 화면에서 고정 PR 검사 및 웹 연결 검사를 다시 실행합니다.

- 웹/프록시: http://127.0.0.1:8768/index.html
- API: 127.0.0.1:8770
- 별도 합성 PostgreSQL: 컨테이너 `originproof-web-test-postgres`, 127.0.0.1:55432
- 별도 로컬 Anvil: 127.0.0.1:18545 / chain ID 31337
- 필요한 기존 도구: Python 3, uv, gh, Docker/Colima, Foundry. 고정 소스 최초 준비에는 네트워크가 필요합니다.
- 테스트 계정·기관 서명키·체인 checkpoint·배포 manifest는 웹 밖 `~/.local/share/originproof-web-test/`에 보관합니다. 해당 폴더는 0700, 비밀 파일은 0600입니다. 브라우저는 HttpOnly 세션 쿠키를 사용하며 토큰/비밀번호/입력 payload를 localStorage에 저장하지 않습니다.
- 실행 파일로 새 서버를 켰다면 그 터미널의 Control+C로 종료합니다. DB를 초기화하지 않습니다.

입력 없이 로그인 버튼을 누르면 기존 디자인 미리보기 동선을 유지합니다. 실제 권한이 생기지는 않으며 보호된 API는 401로 거부합니다. 실제 기능 검사는 준비된 합성 계정으로 로그인해야 합니다.

## 연결한 기능

| 역할 | 실제 연결 |
| --- | --- |
| 사용자 | 서버 로그인/로그아웃, 공개 Proof 조회, 지정 수신자 내용 조회, 지급 요청·공식 문서 필드 비교, 서버 검사 근거·판정 표시 |
| 기관 | 자기 기관 상태/신청 현황, 공개키 목록·등록·정상 교체·폐기, 두 유형 발행 및 저장, 자기 기관 Proof 목록/상세, 수신자 선택, 검증 링크 복사, 감사 이력 및 Operation 재조회/허용된 복구 |
| 관리자 | 운영자 서버 인증, 기관 신청 목록, 승인/반려, 별도 체인 활성화, 시스템 검사 및 웹 연결 검사 재실행 |

기관 ID와 역할은 실제 `/auth/me` 및 서버 권한으로 결정합니다. 사용자가 화면에서 임의 기관으로 전환하지 못하게 했습니다. 같은 발행 입력/요청에는 요청 ID를 유지하고 처리 중 중복 클릭을 막습니다. DB 승인과 체인 CONFIRMED를 따로 표시합니다.

ID 조회는 `PROOF_ONLY`입니다. 받은 자료 내용까지 일치했다고 표시하지 않습니다. 현재 API의 Proof lifecycle 검사 `NOT_RUN`/null을 그대로 표시하며 `VERIFIED`만으로 사용 가능을 선언하지 않습니다.

## 현재 완료할 수 없는 연결

- **Proof 폐기·1회 사용/consume**: 기준 backend에 필요한 ProofStatusRegistry·변경 API가 없어 버튼을 비활성화했습니다. B/C 구현 연결 후 실제 receipt·원자적 중복 사용 거부 검사가 필요합니다.
- **개인 공개 회원가입**: 서버 route가 없습니다. 성공했다고 표시하거나 계정을 브라우저에서 만들지 않습니다.
- **기관 추가 신청 정보**: 현재 신청 API가 받는 정보는 `issuer_name`뿐입니다. 사업자번호/담당자/연락처 등 미지원 입력은 비활성화했습니다. 실제 기업 가입에는 C와 Schema/저장 계약을 확장해야 합니다.
- **신청현황 조회**: 기존 기업명·사업자번호 디자인이 인증을 대신하지 않습니다. 준비된 기관 계정 세션으로 자기 신청만 조회합니다.
- **검증 내역**: 현재 탭 메모리의 최대 50개 요약입니다. 서버 내역 API가 없어서 새로고침 뒤 보존하지 않습니다.
- **QR 이미지/카메라**: 생성·스캔 미연결입니다. 실제 검증 링크 입력/복사는 동작합니다.
- 운영 배포, 실제 외부 기관·개인 데이터, 테스트넷, 유료 AI 호출은 진행하지 않았습니다. 공식 서비스 전체 완료 또는 W 단계 완료로 판정하지 않습니다.
