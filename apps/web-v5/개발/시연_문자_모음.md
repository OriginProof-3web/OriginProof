# 시연용 문자 모음 (AWS 서버 https://52-78-118-236.sslip.io)

로그인한 뒤 '새 대화' 입력칸에 그대로 붙여 넣는다. 모두 합성 데이터(실제 기관·계좌 아님).
서버에 발행된 원본: 오리진 목 은행 10건(계좌 001-234-5000 01~10), 오리진 목 오피스 공문 10건(OMO-2026-0101~0110).

## 시연 순서 (5분)

| # | 보여 줄 것 | 붙여 넣을 문자 | 기대 결과 |
|---|---|---|---|
| 1 | 진짜 안내문 | A1 | ✓ 진짜 안내문이에요 |
| 2 | 금액 1,000원 바꾼 문자 | A2 | ! 가짜 의심 · 금액이 달라요 |
| 3 | 계좌 바꾼 사칭 | A3 | ! 가짜 의심 · 기관 계좌 아님 + AI 위험 높음 |
| 4 | 공문 진짜 | B1 | ✓ 원본 확인 |
| 5 | 없는 공문번호 + 링크 | B2 | ! 가짜 의심 · 공문번호 없음 + AI 위험 |
| 6 | 등록 안 된 기관 사칭 | C1 | 기관 기록 없음 → AI 위험 |
| 7 | 가족 사칭(기관 없음) | C2 | 블록체인 대조 없음 → AI 위험 설명 |

## 참고

- 화면 아래 시연 단추(정상 안내문·금액 1원 변조 등)는 미리 준비된 예시 결과를 보여 준다. 위 문자는 실제 서버 장부와 대조한다.
- 원래 금액·공문 내용은 알려 주지 않는다(남의 청구 금액을 알아내는 데 쓰이지 않도록). "금액이 달라요"까지만 말한다.
- 실제 AI 분석은 계정당 10분 5건 제한이 있다. 리허설은 다른 계정으로.
