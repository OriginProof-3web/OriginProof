# 5안 폴더 안내

| 폴더 | 들어 있는 것 |
| --- | --- |
| `페이지/` | 실제로 여는 화면 파일(HTML·CSS·JS·빌드 결과). 채팅 화면은 `페이지/business.html` |
| `개발/` | 화면 소스(tsx·components)·빌드(`build.mjs`)·로컬 서버·패키지(node_modules) |
| `문서/` | 원래 웹의 기능·시험 설명 문서 |
| `캡처/` | 화면 캡처 |

- 화면만 볼 때: `페이지/business.html`을 브라우저로 열기
- 바로 볼 때: `화면 실행.command` 더블클릭(브라우저로 채팅 화면이 열림)
- 로그인 등 실제 서버까지 켤 때: `개발/협업 테스트 시작.command`(DB·체인·API를 내려받아 켜므로 오래 걸림)
- 소스를 고친 뒤: `개발/`에서 `node build.mjs` → 결과가 `페이지/`에 다시 만들어짐

## 서버 기능 연결 현황 (`phase/W6` `f1d7b3c` 기준)

디자인은 그대로 두고 기존 말풍선·단추 모양에만 연결했습니다. 실서버 모드에서만 서버로 보냅니다.

| 기능 | 화면 자리 | 경로 |
| --- | --- | --- |
| 코드 없는 문자의 원본 찾기 | 채팅칸(기관 이름과 금액·계좌 또는 공문 번호가 있을 때) | `POST /v3/document-lookups` |
| 문서 사진 확인 | 오른쪽 패널에 올린 뒤 '이 사진 확인하기' | `POST /v3/inputs`(`DOCUMENT_IMAGE`) |
| 개인 회원가입 | 가입 화면 | `POST /v1/auth/register` |
| 기관 메일·내부 승인 | 기관 상태 | `/v3/issuer-applications/{id}/…` |
| 공동승인·긴급 정지 | 기관 상태 | `/v3/proposals…`, `/v3/issuers/{id}/suspensions` |
| 체인 네트워크 정보 | 기관 상태 | `GET /v1/chain/network` |
| 문서 검증 자료 | 검색 결과 | `GET /v3/documents/{id}/verification-material` |

- 기관 회원은 가입할 수 없고 운영자가 발급합니다. 가입 화면은 기관 가입을 서버로 보내지 않습니다.
- 서버 기본값은 꺼짐입니다. `API_SIGNUP_ENABLED`, `API_WALLET_IMAGE_INPUT_ENABLED`, `API_WALLET_DEMO_EMAIL_ENABLED`를 켜야 해당 기능이 동작합니다. 사진 글자 읽기에는 OpenAI 키도 필요합니다.
- `POST /v2/issuer/proofs/{id}/register`는 화면에서 부르지 않습니다.
