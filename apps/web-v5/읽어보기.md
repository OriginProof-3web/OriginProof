# 5안 폴더 안내

| 폴더 | 들어 있는 것 |
| --- | --- |
| `페이지/` | 실제로 여는 화면 파일(HTML·CSS·JS·빌드 결과). 채팅 화면은 `페이지/business.html` |
| `개발/` | 화면 소스(tsx·components)·빌드(`build.mjs`)·로컬 서버·패키지(node_modules) |
| `문서/` | 원래 웹의 기능·시험 설명 문서 |
| `캡처/` | 화면 캡처 |

- 화면만 볼 때: `페이지/business.html`을 브라우저로 열기
- 바로 볼 때: `화면 실행.command` 더블클릭(브라우저로 채팅 화면이 열림)
- 로그인 등 실제 서버까지 켤 때: `개발/협업 테스트 시작.command`(DB·체인·API를 내려받아 켜므로 오래 걸림)
- 소스를 고친 뒤: `개발/`에서 `node build.mjs` → 결과가 `페이지/`에 다시 만들어짐
