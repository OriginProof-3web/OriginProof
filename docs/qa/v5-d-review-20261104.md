## D139-02 — 불완전 판독의 구조화 오류 누락

`wallet_analyses.py`의 새 `image_text`는 converter 호출만 try 안에 두고, `prepare_conversion(converted)`는 밖에서 호출합니다. 정상 형식의 `ConvertedText(complete=False)`를 주입하면 기존 guard가 INCOMPLETE_OUTPUT을 발생시키지만 HTTP 경계에서 처리되지 않아500/text/plain이 됩니다. 재호출은 IMAGE_TEXT_ALREADY_READ409로 막힙니다.

이 검사는 실패 경로를 관찰하는 독립 probe1개 PASS이며 제품의 정상 동작 PASS가 아닙니다. 변환 검증을 같은 오류 경계에서 처리해 계약 오류 코드를 반환하고, 자동 재과금/재시도 없이 실패를 표시하도록 요청합니다. 실제 변환기·부정확한 사진을 유료 호출한 결과가 아닙니다.

별도 비정상 HTTP200/complete=false 응답 주입에서는 웹이 일부 텍스트를 일반 TEXT로 넘기는 것도 관찰했습니다. **현재 정상 backend는 prepare_conversion으로 이를 거부하므로, 실제 정상 backend를 통과해 사진 진위를 성공시킨 결함으로 보고하지 않습니다.** JSON에 해당 probe의 경계를 명시했습니다.
