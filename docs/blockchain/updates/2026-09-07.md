# 2026-09-07 — M3/M4 체인 연결 작업

기준: `3bbaba025acd9d692ab484232f778a12a7579702` (`origin/mvp/integration`).

- M3: 기존 계약 코어를 유지하고 ABI·권한·상태·기간 경계를 검증했습니다.
- M4: 문자열 ID Reader, 로컬 배포, 실제 산출물 기반 ABI, SQLAlchemy 이벤트 저장을 추가했습니다.
- 문서: M3/M4 README를 역할별로 분리하고 날짜별 기록 및 M1 handoff를 추가했습니다.
- M1 API 소스, 공통 포트, Makefile, 의존성 manifest·lock, Compose는 변경하지 않았습니다.

이 결과는 “변조”와 “판단에 필요한 시스템 장애”가 섞이지 않는다는 뜻입니다.
live 테스트는 임시 키를 메모리에서 생성해 Golden digest를 서명하며 실제 사용자 키는 사용하지 않습니다.
Proof 저장소는 대역입니다. 운영 DB 연결이나 Docker 전체 서비스 E2E가 완료됐다는 의미는 아닙니다.
