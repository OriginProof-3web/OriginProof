# 본선 시연 리허설·백업 영상 안내

5차 멘토링 피드백("현장 네트워크 대비 리허설 3회 & 백업 영상 확보")을 실행하기 위한 체크리스트입니다. 시연은 로컬 Anvil에서 하고, 공개 체인 증거는 Sepolia 계약 주소와 Etherscan 링크로 보여 줍니다.

- 실행 환경 준비: [W6 RC 개인 재현 안내](w6_rc_personal_reproduction.md)의 1~3단계(`scripts/rc_local.sh up`)
- Sepolia 증거: [Sepolia 배포 런북](sepolia_deploy.md), 계약 `0xe540bf29622afff40174b76992b016112f372a2e`
- AI 지연 대체(선택): [시연 AI 대체 응답](../../apps/web-v5/docs/시연_AI_대체응답.md), 주소에 `&demo_ai_fallback=5`

## 1. 시연 순서 (약 4분)

화면 주소: `http://127.0.0.1:8790/business.html?mode=api` (`localhost`가 아니라 `127.0.0.1`)

| # | 장면 | 입력 | 기대 결과 | 시간 |
| --- | --- | --- | --- | --- |
| S1 | 정상 | `build/rc-local/verify-samples.txt`의 J1 | "발행 기록 확인", 원본 일치 "일치", 상태 "유효" | 1:00 |
| S2 | 금액 1원 변조 | 같은 파일의 J2 | "원본과 다름", 원본 일치 "불일치" | 1:00 |
| S3 | 미등록 사칭 | 시연 프리셋 `미등록 기관 사칭` | 발행 "기록 없음" + AI 위험 신호(원격 지원 앱 설치 유도) | 1:00 |
| S4 | 증거 | 발표 자료의 Sepolia 장 | 계약 주소·Etherscan 링크·2-of-3 승인 타임라인 | 1:00 |

실서버 시드 안내문 금액은 v1 154,000원·v2 120,000원입니다. 발표 자료의 85,000원 예시와 다르므로 말할 때 "시연 데이터의 금액"으로 말합니다.

## 2. 리허설 3회

매회 아래 표를 채웁니다. 비밀번호·키·토큰은 적지 않습니다.

| 회차 | 네트워크 | 목표 |
| --- | --- | --- |
| 1 | 평소 Wi-Fi | S1~S4를 시간 안에 끝내기, 대본과 화면 순서 맞추기 |
| 2 | 휴대폰 핫스팟 | 실제 AI 응답 시간 재기, 느리면 `demo_ai_fallback` 켜고 다시 |
| 3 | 핫스팟 + 중간에 끊기 | 실패 상황에서 백업 영상으로 10초 안에 넘어가기 |

```text
[리허설 n회차] 날짜 / 장비 / 네트워크
RC SHA: (git rev-parse HEAD)
S1 S2 S3 S4: 통과/실패, AI 응답 시간(초)
전체 시간: m:ss
막힌 곳·바꿀 점:
```

## 3. 백업 영상

- 2회차 리허설이 성공하면 그 화면을 녹화합니다. macOS는 `Cmd+Shift+5` → `전체 화면 기록` 또는 `선택 부분 기록`.
- 내용: S1 → S2 → S3 순서, 장면마다 결과 화면에서 2~3초 멈춤. 소리 없이 녹화하고 현장에서 말로 설명합니다.
- 파일은 저장소에 올리지 않고 발표 노트북 바탕화면과 USB 두 곳에 둡니다. 계정·키가 보이는 창(터미널, 설정)은 녹화 전에 닫습니다.
- 시연 직전에 영상 파일을 한 번 열어 재생되는지 확인합니다.

## 4. 현장 직전 점검 (5분)

| 확인 | 명령·방법 |
| --- | --- |
| 서비스 상태 | `scripts/rc_local.sh status` → DB running, Anvil 31337, API 200, 웹 200 |
| 로그인·실서버 모드 | 기관 계정 로그인 → `기관 상태` → `실서버 모드로 바꾸기` |
| 샘플 문장 | `build/rc-local/verify-samples.txt` 열어 두기 |
| 백업 | 백업 영상, 발표 PDF를 바로 열 수 있게 두기 |
| 절전 | 화면 잠금·절전 끄기, 알림 끄기 |

## 5. 실패 시 전환

| 증상 | 바로 할 일 |
| --- | --- |
| AI 칸이 오래 비어 있음 | `demo_ai_fallback` 켠 주소로 다시 열기, 또는 "AI는 보조이고 발행 판정은 이미 나왔다"고 말하고 다음 장면 |
| API·웹이 응답 없음 | 백업 영상으로 전환 |
| 네트워크 끊김 | 로컬 Anvil이라 시연은 계속 가능. Sepolia는 발표 자료의 주소·링크로 대신 |
